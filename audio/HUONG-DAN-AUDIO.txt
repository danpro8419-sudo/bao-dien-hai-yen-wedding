AUDIO V11 — CÁC FILE CẦN UPLOAD

Tạo thư mục `audio/` ở root GitHub và đặt các file:

audio/
├── opening-instrumental.mp3   <- nhạc nền cố định khi mở link
├── vow-intro.mp3              <- đoạn lời hứa / giọng nói
├── playlist-01.mp3
├── playlist-02.mp3
├── playlist-03.mp3
├── playlist-04.mp3            <- tùy chọn
└── playlist-05.mp3            <- tùy chọn

LUỒNG ÂM THANH:
1. Web thử phát opening-instrumental.mp3 rất nhỏ khi mở link.
2. iPhone/Chrome mobile có thể chặn autoplay có tiếng. Khi đó, lần chạm đầu tiên sẽ tự mở khóa nhạc.
3. Bấm con dấu / tấm thiệp:
   - instrumental hạ nhỏ
   - vow-intro.mp3 phát phía trước
   - lời hứa hiện bên trái (mobile: phía dưới)
4. vow-intro kết thúc:
   - instrumental fade-out
   - playlist bắt đầu ngẫu nhiên
5. Mỗi lượt khách phát tối đa 3 bài, không lặp lại trong lượt đó.

ÂM LƯỢNG mặc định nằm trong config.js:
- openingVolume: 0.16
- vowVolume: 0.86
- playlistVolume: 0.28

Bạn có thể sửa `vowLines` trong config.js để khớp câu nói thật.

LƯU Ý BẢN QUYỀN:
Code không kèm các bài nhạc thương mại. Hãy upload file âm thanh mà bạn có quyền sử dụng / đã được cấp phép.
